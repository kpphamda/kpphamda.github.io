Paste these in the Firebase console under Firestore Database -> Rules -> Publish.
They replace the test-mode rules, which stop working after 30 days.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // crop data: any signed in user may read it, and only you can change it from the console
    match /countries/{countryId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null;

      match /crops/{cropId} {
        allow read: if request.auth != null;
        allow write: if request.auth != null;
      }
    }

    // contact messages: a signed in user may send one, and nobody can read them from the site
    match /messages/{messageId} {
      allow create: if request.auth != null
                    && request.resource.data.submittedBy == request.auth.uid;
      allow read, update, delete: if false;
    }
  }
}

Note: the write rule on /countries is what lets setup.html upload the data while you are
logged in. Once the upload is done you can change those two write lines to "if false" so
nobody can overwrite the crop data from a browser.
